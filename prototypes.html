AI State Machines & Evasion Mechanics

  • State Machines (Patrol vs. Chase): I programmed the enemy's behavior by structuring independent logic flows: a passive patrol along a predefined path and an aggressive state that takes control of movement the moment the player enters the detection range.
  • Line of Sight and Stealth: I implemented a vision system that constantly evaluates obstacles. To escape, the player must read the environment and use maze walls to break the direct line of sight, forcing the enemy to abandon the chase and resume its original patrol route.
  • Game Flow (Fail State): I set up an immediate penalty loop where colliding with the enemy transports the player back to the starting point (respawn). This creates a self-contained sandbox environment ideal for repeatedly iterating on evasion mechanics without loading screens.

    • Probability Scoring & Physics Debugging

  • Scoring System (Triggers): I programmed the point-collection logic using detection zones (triggers) at the bottom, assigning variable values that are dynamically added to the player's total score based on the bin where the sphere lands.
  • Chance-based Mechanics: I designed the board layout to ensure the trajectory of each drop is unpredictable, evaluating how physical randomness interacts with player expectations within an endless gameplay loop.
  • Physics Evaluation and Iteration: During testing, I identified a retention issue where spheres lose momentum and get stuck on obstacles, despite there being sufficient clearance. The next iteration step involves auditing the Physics Materials in Unity (reducing friction to zero and adjusting bounciness) and fine-tuning the Rigidbody's continuous collision detection.

    • System Debugging, AI & Wave Management

  • Collision Physics (Vectors): Corrected the directional math for impacts. Modified the vector subtraction logic between positions to ensure the repulsion force pushed enemies away upon collision, rather than pulling them toward the player.
  • Artificial Intelligence: Debugged critical assignment errors (resolving NullReferenceExceptions) to dynamically link the player's net as the enemies' primary target, causing them to actively seek to score instead of remaining stationary.
  • Progressive Difficulty (Pacing): Structured the Spawn Manager to mathematically scale the challenge. Programmed conditional loops that increase both the number of spawned enemies and their base movement speed with each new round.
  • Ability Systems (Coroutines): Implemented an input-activated "Turbo Boost" featuring visual feedback (particle systems). Additionally, fixed the power-up lifecycle using coroutines to ensure that stat boosts correctly expired after a set duration.

    • Debugging & System Implementation

  • Interaction Logic: I fixed critical errors in player input by replacing passive collision detection (OnMouseEnter) with active clicks (OnMouseDown) to ensure that point collection was intentional.
  • Difficulty Balancing: I structured a difficulty parameter that communicates directly with the Game Manager, dynamically altering the object spawn rate based on the selected mode (Easy/Hard).
  • Time and Status Management: I implemented a strict 60 second countdown timer using Time.deltaTime and Mathf.Round(). I integrated it with the Game Over sequence, ensuring the UI (scores and restart buttons) responded correctly to changes in the game state.
